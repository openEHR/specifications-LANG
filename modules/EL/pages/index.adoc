= {spec_title} [.spec-status.spec-status-development]#{spec_status}#

A formal syntax for computable expressions covering arithmetic, relational, logical, and function call forms, used in archetype rules, decision logic, and guideline conditions. EL is the full expression language of the openEHR platform; BEL is the boolean-only subset used where only predicate conditions are required. EL supports typed variables, function definitions, and operator precedence rules aligned with standard mathematical conventions.

== Purpose

This document specifies an abstract openEHR Expression Language (openEHR EL) that provides a syntax counterpart to the `expression` package in the {openehr_bmm}[openEHR Basic Meta-Model (BMM)^]. This may be used within BMM models, to specify archetype rules, {openehr_task_planning}[Task Planning^] expressions, in newer versions of {openehr_cds_releases}[GDL^], and in decision language expressions.

The intended audience includes:

* Standards bodies producing health informatics standards;
* Academic groups using openEHR;
* Solution vendors.
